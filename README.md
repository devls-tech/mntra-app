# Mntra

A flashcard learning app for Android — with spaced repetition, swipe-to-rate, flags, icons, audio and image slots, and no cloud.

This repository is the **public landing** for Mntra: privacy policy, website, and the place to file issues. The app source lives in a separate private repo.
